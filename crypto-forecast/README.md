# Crypto Forecast API

Backend σύστημα πρόβλεψης της κατεύθυνσης της τιμής του Bitcoin με χρήση ιστορικών δεδομένων αγοράς, δεδομένων Google Trends και τεχνικών Μηχανικής Μάθησης.

Το σύστημα προβλέπει αν η τιμή κλεισίματος του Bitcoin κατά την επόμενη ημερήσια περίοδο θα κινηθεί ανοδικά ή καθοδικά.

## Κατηγορίες πρόβλεψης

- `0` = `DOWN`
- `1` = `UP`
